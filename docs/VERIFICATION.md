## Automated coverage

The 9 unit tests cover three-hit elimination, score/death increments, respawn and protection, walls blocking shots, duplicate-shot and cooldown behaviour, shield cancellation on firing, reload completion, stale-input stopping, normalized diagonal movement, the five-minute round boundary and simultaneous score resets, sprite dimensions, terminal resize and overlay rendering.

The 6 integration tests cover two real UDP clients joining a background server, replicated names/colours/movement, initial score state and round timer, leave propagation, malformed and oversized packets, rejected forged identity/invalid input, bounded eight-player snapshot size, an enclosed connected arena, collision substeps, safe names and sequence wraparound.

Combat hit/scoring logic and round expiry are tested in the deterministic simulation. The two-client integration test validates transport and replication; it is not a recorded human multiplayer match.

The round-boundary test advances simulation time around 300 seconds. It does not wait five wall-clock minutes.

## Reproduce the terminal smoke check

On Linux or another Unix system with Python 3 and a built release executable:

```sh
python3 scripts/terminal_smoke.py
```

This creates two pseudo-terminals, uses a temporary localhost UDP port, opens the scoreboard/help, and checks graphics output and cleanup. The script is Unix-specific and is not required to build or play on Windows.

To regenerate the deterministic visual preview:

```sh
cargo run --locked --example preview > docs/renderer-preview.svg
```
